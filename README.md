# 🚀 Projectile Motion Tracker

An interactive web app built using Python and Streamlit to calculate and visualize projectile motion.

## ✨ Features
- Calculate time of flight.
- Calculate maximum height.
- Calculate horizontal range.
- Visualize the projectile's trajectory.

## 🛠️ Technologies Used
- Python
- Streamlit
- NumPy
- Matplotlib

## ⚙️ Run Locally

Install the required libraries:

```bash
pip install -r requirements.txt
```

Run the app:

```bash
python -m streamlit run app.py
```

## 📐 Physics Model

The app assumes ideal projectile motion without air resistance, with the projectile landing at its launch height. Gravity is taken as 9.8 m/s².
